# 2.2.2 牌面与界面说明

采用 [lietxia/mahjong_graphic](https://github.com/lietxia/mahjong_graphic) 的默认风格竖向牌面及藏蓝色竖向牌背 `b_02.png`，上游版本固定为 `3e275804ff58325306710bef3a7406860444bc6a`。

仅使用 34 种标准牌面：一至九万、一至九筒、一至九条、东南西北中发白。每种四张，牌局仍为 136 张。没有导入赤五、花牌、季节牌或其它特殊牌。耗子继续以现有标准牌指定，不增加新的牌种。

手牌、四家弃牌、副露、单机结算牌使用同一套素材；未知手牌及报听时盖住的弃牌使用统一牌背。牌图按比例缩放，较小弃牌使用逐级缩小及尺寸缓存以保持细节，选中牌仍有金色边框和抬起效果。牌桌采用深绿桌布、藏蓝面板和浅色操作区。

引擎编号 31/32/33 为中/发/白，而素材编号 5z/6z/7z 为白/发/中，渲染层已单独映射。2.2.2 沿用同一套牌图及画风；自动回位与听后锁牌行为见 README.md，建议四人一起更新。

完整牌面预览见同目录 `tile-catalog.png`。许可证见 `licenses/mahjong-graphic-LICENSE.txt`；每张原图的来源和 SHA-256 在 `source.zip` 的 `src/main/resources/assets/tiles/manifest.json` 内。构建不依赖网络；可选 `tools/fetch-artwork.ps1` 用于重新取得固定版本的原图。

## 检查方法

1. 打开牌面预览，确认万筒条各九种、七种字牌，中为红字、发为绿字、白为空白。
2. 启动程序，选择单机练习，检查点击、双击、提示、碰杠和结算中的牌面。
3. 按 `MULTIPLAYER_TEST.md` 启动四个客户端，检查每个人自己的手牌位置正确，其他人的手牌仍为牌背；准备、出牌、断线恢复、下一局正常。
4. 双击 `test-network.cmd` 可运行四客户端 TCP 自测。真实跨国连接仍需你们用 Tailscale 实测。
