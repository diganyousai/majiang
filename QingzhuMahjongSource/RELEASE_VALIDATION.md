# 青竹扣点点 2.2.2 验证记录

日期：2026-10-27。Windows x64，Eclipse Temurin JDK 21.0.12.1+1，jpackage app-image 自带运行时。

## 本次行为

1. 加入界面和牌桌移除手输恢复码。每个本机昵称自动保存随机身份，客户端关闭后，原电脑、相同 Windows 用户与昵称再次加入即可回到活动牌局原座位，保留手牌、分数及报听状态。主机仍需保持运行。
2. 尚未开局时，离线客人席位可供新人使用；若原席位还未被新人使用，原玩家优先恢复原位。活动牌局不允许他人替补或只凭相同昵称冒领手牌。
3. 报听后原手牌不可点击换出，不能碰或再次报听；平时只能胡牌或打刚摸到的牌。保持听口不变时允许明杠、暗杠和补杠，杠分沿用原规则；补牌后仍只可胡或打补到的牌。

身份文件保存在 `%LOCALAPPDATA%/QingzhuMahjongOnline/identities/`。只保存随机身份，不保存房间口令。删除身份文件、换 Windows 用户、换电脑或更换昵称不能自动证明是原玩家。主机重启后不能恢复旧牌局。

## 规则、身份及网络检查

- 35,933 条规则断言、14,636 条对照牌例及76场规则对局通过。
- 检查旧手牌及相同牌面的旧副本均不可选，刚摸的牌仍可选；非法动作不得修改状态，摸打后完整13张原手牌和听口不变。
- 检查报听后的合法明杠、暗杠和补杠，三种杠均保持听口并沿用普通付款规则；改变听口的杠被拒绝。合法自摸、点炮及风嘴子仅自摸规则保留。
- 固定牌例检查“旧1111万和23万，摸4万后暗杠旧1万”的情况：即使听口不变，也会把123万变成234万，因此拒绝。听后自家暗杠或补杠必须使用刚摸到的牌，不能借杠换手牌。
- 真实回环 TCP 验证：重新实例化身份存储和客户端、不传恢复码，自动恢复大厅席位及活动牌局原位；房主也能自动回0号位。
- 退出的大厅客人席位可被新人复用；另一套身份即便使用同昵称，也不能抢活动牌局座位。
- 真实网络发送换牌、无对应碰牌的补杠及再次报听请求，服务端返回 INVALID_ACTION，状态保持不变。合法听后暗杠经 TCP 执行，金币场每家按普通暗杠金额实时付款。
- 自动恢复后报听状态和原手牌仍保持；身份进入重建的新房间不受旧连接凭据影响。
- 保留7局完整四客户端网络回归、固定多家响应、幂等、隐私与结算检查。

## 手工验收

1. 四人入座但不准备，关闭一位客人的客户端；确认该席位显示为空位，第五位新人可以加入。原玩家若先于新人返回，应回原位。
2. 四人开始一局，关闭其中一个牌桌（不关闭主机）；用同一电脑和昵称重开加入，无需输入恢复码，确认回原位、手牌和分数相同。
3. 报听后点击原手牌，确认不能换选；出牌只打刚摸的牌，碰按钮不出现。合法杠可操作，杠后听口不变、杠分与普通杠相同；有合法胡牌时仍可胡。
4. 报听后关闭再加入，确认“[听]”、手牌及锁牌限制仍在。局末“查看全场牌”以及下一局的私牌隔离仍正常。
