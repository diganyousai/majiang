# 青竹扣点点 2.2.1 验证记录

日期：2026-10-26。Windows x64，Eclipse Temurin JDK 21.0.12.1+1；Windows app-image 自带运行时。

## 本次范围

1. 风嘴子组成的胡牌只能自摸，不可点炮或抢补杠胡。普通成牌拆法仍能按原规则接炮；此时不能选择风嘴子分组计分。
2. 胡牌或荒庄后，对四位玩家公开手牌、弃牌及副露（含暗杠、原盖住的报听弃牌）。结算窗口和牌桌增加“查看全场牌”。下一局关闭查看窗口并恢复私牌隔离。不公开未摸牌墙。

其余牌面素材、计分、默认选项、网络协议格式和联机配置保持原样。版本号更新为 2.2.1。

## 针对性验证

- 规则回归：35,919 条断言、14,636 条上游对照牌例、76 场规则对局通过。
- 新用例包含须报听/无需报听的风嘴子自摸、点炮拒绝、抢杠拒绝、普通接炮保留、可同时按普通或风嘴子拆分时的接炮计分。
- 公开边界：行牌时他人手牌、报听弃牌及暗杠仍隐藏；局末四家都收到真实牌面；旧快照不被修改，下一局重新隐藏。荒庄同样验证。
- 回环 TCP 测试：7 局通过，验证局末四人的公开牌面完全相同；下一局私牌隔离恢复。
- 四个真实 Swing 客户端的 60 条事件派发检查通过：选择出牌、暂停恢复、结算、每家打开全场牌窗口、下一局自动关闭窗口并隐藏他人手牌。
- 已查看 `online-full-table.png` 和 `online-revealed-board.png`，确认展示四家手牌、副露及弃牌。
