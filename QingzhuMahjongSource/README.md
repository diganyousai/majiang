# 青竹麻将 · 山西扣点点 2.2.2

Windows x64 程序：支持一人开房、四位真人入座准备与对局，也保留一位真人加三个机器人的单机练习。支持亲友房设置及金币场固定规则（仅模拟积分）。跨国使用自己的电脑作主机，配合Tailscale组网。

采用 mahjong_graphic 默认风格牌面，只含扣点点使用的 34 种标准牌面（136 张），没有赤五、花牌或额外牌种。预览见 **tile-catalog.png**，素材说明见 **ARTWORK.md**。

四人入座、局域网、跨国组网、断线恢复及自动测试的完整步骤见 **MULTIPLAYER_TEST.md**。代码边界见 ONLINE_DESIGN.md。

## 使用方法

解压 `QingzhuKouDianDianOnline-2.2.2-Windows-x64.zip`，进入文件夹，双击 `QingzhuKouDianDianOnline.exe`。

无需安装 Java。请保留 EXE 同目录的 `app`、`runtime` 文件夹，不能只发送一个 EXE。

另附 `play.cmd`，可通过随包 Java 运行时启动同一个游戏，无需系统 Java。EXE 尚未进行商业代码签名，严格应用控制策略可能拦截。`play.cmd` 是标准 Java 启动入口，不会修改防火墙、系统安全设置或证书信任。若你的设备策略限制程序运行，应遵循设备管理员的规定。

启动时选择“单机练习”“创建联机房间”或“加入联机房间”。主机选择玩法和房间选项，再把IP、端口、房间号、口令告诉朋友。四人分别准备后开局；默认TCP端口17890。主机小窗口要保持打开。

加入无需恢复码。本机按昵称自动保存玩家身份；关闭客户端后，在同一电脑、同一 Windows 用户下使用相同昵称再次加入，会自动恢复活动牌局的原座位、手牌和分数。身份文件位于 `%LOCALAPPDATA%/QingzhuMahjongOnline/identities/`，不保存房间口令；请保留该目录。换电脑、更换昵称或删除身份文件不视为同一玩家。四人更新后请重新建房使用新版。

开局前离线的玩家席位显示为空位，新人可入座；原玩家返回时，原席位尚未被别人使用则自动回原位，已被替换则按剩余空位入座。对局开始后不替换玩家，掉线暂停，原玩家自动回位后继续。

默认亲友房：136张、不可吃、必须报听、报听至少有一个6点以上听口；无耗子、无牌型翻倍/加点、无风嘴子、无带庄或额外包杠。

亲友房牌型数值按要求留空。在“牌型计分”页选择翻倍或加点、勾选牌型并手动填入数值后才生效。选择耗子后不能选择牌型计分。跟庄判定待定，未启用；“点炮者包胡家杠”单独选项也不启用。

## 单机练习操作

- 点击手牌选择，再点“出牌”，或双击手牌出牌。
- 满足报听门槛时出现“报听”；多种报听弃牌可从菜单选择。报听动作同时盖住弃牌，其他人不能碰、杠、胡这张牌。
- 报听后显示“[听]”，自动选中刚摸到的牌，原手牌不能点击换出，不能碰或再次报听。可胡牌或打刚摸的牌；保持原听口不变时允许明杠、暗杠和补杠，杠分计算与普通杠相同。自家暗杠或补杠必须使用刚摸到的牌，不能借旧杠将无关新牌换入手中；杠后补牌同样遵守锁牌规则。
- 可以响应碰、明杠、暗杠、补杠、胡、过。没有吃牌。
- 提示选中建议弃牌；托管由机器人代打；暂停冻结自动行动。
- Enter 出牌，H 提示，空格暂停/继续。
- “规则”显示当前设置；“新建牌桌”重新选规则并开始新积分场。
- “重新开局”回退本局已入账积分、重新发牌；此前完成各局积分保留。
- 结算窗口显示净变化、总分及每笔付款明细；下一局由胡家坐庄，荒庄留庄。

## 已确定的主要规则

序数牌1～9点，字牌10点，胡点取胡进牌。1、2点不能胡；3、4、5点仅自摸；6～10点可自摸、点炮、抢补杠胡。多人同时胡按行牌顺序近者截胡，一炮一胡。

自摸每家支付，胡分乘2。未报听点炮者承担三家的总额；报听后点炮三家各付。默认直杠在点杠者未报听时承包，报听后每家一份；也可选择一直承包或一直三家出。补杠每家一倍牌面值，暗杠每家两倍。

金币场固定倍数：混一色2、清一色3、一条龙2、七对2、豪华七对4、十三幺4，适用倍数相乘，另乘自摸2倍；杠分实时入账，最终结算不重复收费。

耗子是万能牌，开局发牌后随机公布；可选随机一个牌种、随机一种字牌、随机两个不同牌种。耗子规则不允许七对与十三幺。耗子牌直杠、暗杠每家40分。

风嘴子只有开启后生效：不同三风或中发白组成一组，一组5分，自摸翻倍。依赖风嘴子成牌的胡牌只能自摸，不能点炮或抢杠胡；同一手牌有普通成牌拆法时，可按普通拆法接炮，不计风嘴子分。

一局结束（胡牌或荒庄）后，四家手牌、弃牌、副露和暗杠对所有玩家公开。结算窗口或牌桌上的“查看全场牌”可打开大图查看，包括原先盖住的报听弃牌。下一局开始后关闭旧查看窗口，并重新隐藏他人手牌。尚未摸出的牌墙不展示。

完整差异、留白项目及工程解释见 `RULES_AUDIT.md`。本程序没有真钱功能，不保存未结束牌局或累计积分到磁盘。

## 构建与验证

源代码在 `source.zip`。需要 Windows x64 JDK 21+，无 Maven / Gradle 依赖。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -JdkHome 'C:\path\to\jdk-21' -TestOnly
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -JdkHome 'C:\path\to\jdk-21'
```

脚本先校验素材白名单和 SHA-256、编译和运行规则/牌面/联机测试，再生成 JAR、精简运行时、Windows EXE 与 ZIP。产物在 `dist/`。源码目录为工作区的 `QingzhuMahjongSource`；发布包中的 `source.zip` 是同版源码快照。

单机图形冒烟测试会打开程序窗口并自动操作鼠标，请在不使用鼠标时执行：

```powershell
.\dist\QingzhuKouDianDianOnline\QingzhuKouDianDianOnline.exe --smoke-test 'C:\absolute\test-output'
```

四人TCP自动测试可双击分发目录 `test-network.cmd`；四窗口图形测试为 `--network-smoke`，详见 MULTIPLAYER_TEST.md。主机状态存于内存，主机退出不能恢复牌局；客户端暂时断线会暂停并自动重连。

源码模块：`Rules` 配置，`HandRules` 牌型，`Scoring` 账本，`Game` 状态机，`RoomServer/RoomClient/RoomProtocol` 联机，`MultiplayerWindow/RoomDialogs` 联机界面，`GameWindow/Board` 单机及共用牌桌。

原向听算法及14,636个对照样例保留。扣点点胡牌与计分由新模块处理；机器人沿用向听启发式，优先合法胡牌与报听，不保证最优打法。

异常日志：`%LOCALAPPDATA%/QingzhuMahjongJava/error.log`。音效和节奏偏好使用当前用户 Java Preferences。许可证见 `THIRD_PARTY_NOTICES.md`、`licenses/` 和 `runtime/legal/`。
